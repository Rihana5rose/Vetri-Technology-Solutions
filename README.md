# Job Portal Analytics

## AI-Powered Recruitment Analytics, Prediction & Business Insights

An end-to-end Job Portal Analytics project developed during my internship at **Vetri Technology Solutions**.

This project analyzes IT job-market data using Excel, SQL, Python, Machine Learning, and Power BI to identify job-market trends, salary patterns, candidate insights, and business opportunities.

---

## 📌 Project Overview

The project uses real-time IT job-market data along with candidate profile data to perform data cleaning, exploratory analysis, SQL-based business analysis, machine learning, and interactive dashboard development.

### Key Objectives

- Analyze IT job-market trends
- Understand job distribution across locations and work modes
- Analyze skills and experience requirements
- Perform salary analysis and prediction
- Analyze candidate profiles
- Predict candidate shortlisting
- Build interactive Power BI dashboards
- Generate meaningful business insights and recommendations

## 📊 Dataset

The project uses:

- **5,591 IT job listings**
- **1,388 companies**
- **30 cities**
- **1,000 candidate profiles**

The job listings were sourced during **17–23 August 2026**, with **23 August 2026** as the last source/reference date.

The candidate dataset contains synthetic candidate profiles created for analysis and prediction.

1. Salary Prediction

Machine learning models were developed to predict job salaries based on relevant job-related features.

Random Forest Regression

Model performance was evaluated using:

RMSE
R² Score
2. Candidate Prediction

A classification model was developed to predict whether a candidate is likely to be shortlisted based on candidate-related features.

Model Used:

Logistic Regression

Evaluation Metrics:

Accuracy
Precision
Recall
F1 Score
